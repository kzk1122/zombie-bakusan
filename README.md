# ゾンビ爆散

迫り来るゾンビの大群を、マシンガンとロケットランチャーや戦車、メダルで手に入るブラックホール・レールガン・波動砲・火炎放射器・電撃砲・ミサイルで吹き飛ばす15秒1本勝負の3Dブラウザゲームです。舞台は夜の大通り、夜の遊園地、夏祭りの参道で、トゲ付き鉄線フェンスが最終防衛ラインです。

**遊ぶ: https://zombie-bakusan.pages.dev/**

![ゲーム画面](screenshot.jpg)

## 遊び方

- タイトル画面で武器を選びます。最初は「ロケラン」と「戦車」で、メダルを集めると「ブラックホール」（10枚）、「レールガン」（20枚）、「波動砲」（30枚）、「火炎放射器」（40枚）、「電撃砲」（50枚）、「ミサイル」（60枚）が使えるようになります
- タイトル画面ではステージも選べます。「大通り」「遊園地」「夏祭り」のどれか、または「おまかせ」（毎回ちがうステージ）です
- ロケランは長押しでマシンガン、タップでロケット
- 戦車は長押しで機銃、タップで主砲。主砲は連射が遅いかわりに、並んだゾンビを串刺しにして突き抜けてから大爆発します
- ブラックホール、レールガン、波動砲、火炎放射器、電撃砲、ミサイルも長押しはマシンガンです。タップするとブラックホールはゾンビや車を吸い込んでから大爆発する黒い穴、レールガンは照準の先まで一瞬で貫く光線、波動砲は充填120%のあと通りを一直線に消し飛ばす極太ビーム、火炎放射器は浴びたゾンビが火だるまで走り回って周りに燃え移り、黒焦げで弾ける炎、電撃砲は群れを次々に飛び移り、骨まで透かしてから弾けさせる稲妻、ミサイルはロックオンした群れやドラム缶に10発が弧を描いて次々に突っ込む乱れ撃ちを出します
- PCは右クリックかスペースキーでもロケットや主砲などタップの武器を撃てます。画面はスマホと同じ縦長で、中央に表示します
- ドラム缶と車は撃つと大爆発、手前のビルはロケットを何発か当てると崩れて、その側の道にいるゾンビと車を下敷きにします。戦車の主砲なら一撃です
- 爆発すると道路もえぐれて、アスファルトの塊が舞い上がります。穴は赤く焼けたひび割れを残し、その回の間ずっと道路に残ります
- 倒し続けると左下のメーターが溜まり、満タンになると空爆が自動で飛んできます。戦闘機3機が奥から低空で迫り、大通りをフェンスの手前まで絨毯爆撃します。同時にFEVER（マシンガン2倍とタップの武器の撃ち放題、戦車は機銃2倍と主砲の連射）になります
- ゾンビは最大170体が同時に押し寄せます。奥から来るほか、フェンスのすぐ先のマンホールからも這い出てきます
- 倒すと金貨と札束が舞う金ピカのゾンビ、撃つとボンベが火を噴いて飛んでいき大爆発するボンベ背負い、膨れ上がって破裂し周りをなぎ倒すデブのゾンビも混じります
- 毎回ひとつハプニングが起きます。突っ込んでくるタンクローリー、ゾンビ満員の観光バス、取材ヘリ、通りの真ん中で火を噴きはじめるガス管のマンホール6つ（撃つと火柱が次々に上がって群れを打ち上げます）、ゾンビをロープにぶら下げてサーチライトで通りを照らすゾンビ飛行船（ぶら下がりを撃ち落とすか、船ごと落とすと墜落して乗客が投げ出されます）のどれかで、撃てば派手に吹き飛びます
- 夜の遊園地では、奥の観覧車にロケットを何発か当てると手前に倒れてきて、ゴンドラが群れに飛び込んで爆発します。右上を走ってくるジェットコースターを撃つと脱線して、車両が1両ずつ群れに突っ込みます
- 夏祭りでは、参道の奥にある花火の打ち上げ台を撃つと大スターマインが始まります。花火が群れのいちばん濃いところへ次々に飛んで頭の上で破裂し、最後に鳥居の奥で尺玉が開きます
- 毎回3つのお題（銅・銀・金）が出ます。達成するとメダルがもらえ、集めたメダルで新しい武器が解放されます。お題とメダルはそのブラウザに保存されます
- 途中で巨大ゾンビが来ます。空から1体降ってくるか、2体同時に降ってくるか、燃えながら霧の奥から駆けてくる巨大ゾンビ犬のどれかです。倒すと月まで飛んでいき、2体同時なら2体目は星になって「キラーン」と消えます。遠くまで吹き飛んだゾンビが月に当たることも
- 15秒たつと、残ったゾンビも車も巨大ゾンビもまとめて大爆発します
- 負けはありません。点になるのは、自分の弾から始まった爆発や誘爆、吹き飛んだ体のストライク、崩したビルで倒したゾンビだけです。1発で11体目からは2倍、ヘッドショットも2倍。15秒で稼いだ点数でランク（C / B / A / S / SS / SSS）が決まります
- 結果画面では、その回いちばん大きな連鎖をスローで再生します
- 結果はXやLINEでシェアできます。スマホではフィナーレの写真に点数を載せた画像で共有、PCではその画像を保存できます
- Androidのスマホでは、空爆や波動砲、巨大ゾンビなど大きな場面で短く振動します

最初に作った2D版も遊べます: https://zombie-bakusan.pages.dev/2d/

## 中身

- `index.html` が3D版、`2d/index.html` が2D版です。どちらも1枚のHTMLで、ビルドなしでブラウザから開けます
- 3D版の描画は [three.js](https://threejs.org/)（MIT、r182）で、jsDelivr から読み込みます。街もゾンビもコードで組み立てています
- 2D版は Canvas 2D の疑似3D で、外部ライブラリは使っていません
- 効果音は Web Audio でその場で合成しています
- 実況とうめき声は [Kokoro TTS](https://huggingface.co/hexgrad/Kokoro-82M)（Apache-2.0）で生成し、ファイルに埋め込んでいます
- フォントは Google Fonts の [Dela Gothic One](https://fonts.google.com/specimen/Dela+Gothic+One) と [Zen Kaku Gothic New](https://fonts.google.com/specimen/Zen+Kaku+Gothic+New)（SIL Open Font License）です
- アクセス解析に Google Analytics（GA4）を使っています。ページの表示のほか、ゲームの開始と終了（武器・ステージ・ランク・点数）、空爆、シェアのボタンをイベントとして送ります
